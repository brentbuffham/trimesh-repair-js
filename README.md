# trimesh-repair-js

Repair functions for the trimesh family of JavaScript meshing libraries
([trimesh-boolean](https://github.com/brentbuffham/trimesh-boolean),
[trimesh-build-js](https://github.com/brentbuffham/trimesh-build-js)).

> **Placeholder (0.0.0).** Nothing to use yet. The repair functions are being built and proven inside
> [Kirra](https://kirra-design.com) first, then moved here. The first working release will be 0.1.0.

## Planned

- Find open boundary loops; patch them (auto, fair, fan, centroid, vertex fan)
- Close and fill open meshes; weld; orientation and normals
- Mesh checks: closed, non-manifold edges, enclosed volume
